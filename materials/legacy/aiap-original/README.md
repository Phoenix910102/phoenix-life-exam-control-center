# AIAP Original Material Archive

This directory preserves the original standalone AIAP material pages that
preceded the data-driven Phoenix Campaign version.

## Snapshots

- `aiap-hyperlinked-glossary.html`: hyperlinked glossary edition.
- `aiap-progress-fixed.html`: repaired progress-bar edition.
- `aiap-chapter-progress.html`: chapter checkbox and progress edition.
- `aiap-battle-rose.html`: latest Battle Rose edition with applied scenarios,
  quiz flows, achievements, and the floating care console.

## Supporting files

- `assets/`: only the image assets referenced by the archived pages.
- `quiz/`: the original boss quiz, final exam bank, and quiz engine.

## Relationship to the current app

These files are historical, read-only snapshots. The current application uses
`materials/generated/aiap-intermediate-complete-guide.phoenix-material.json`
and the shared `/campaigns/[slug]` renderer so that progress, display modes,
and Command Center reporting remain unified.

Do not edit these snapshots when changing the current AIAP campaign. Update the
versioned Phoenix material package and shared campaign components instead.

Official exam PDFs, DOCX files, local tools, temporary backups, and personal
study data are intentionally excluded from this archive.
