# UI Guide

## Layout
- Top navigation header with section chips.
- Card-first composition for all panels.
- Warm gradient background and high-contrast cards.

## Interaction
- `/console` provides ingestion controls in four required panels.
- `/settings` handles model switch, JSONL import, and export generation.
- `/games` includes Framer Motion hover/glow animation.

## Responsive
- Mobile uses single column cards.
- Desktop switches to multi-column grids for summary/game views.
